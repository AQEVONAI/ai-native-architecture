# 07 — Exercises

## Exercise 1 — Re-run the assessment and compare profiles

Run `assessment/assessment-questionnaire.md` fully against the three-capability portfolio (support assistant, ticket agent, workload assistant) and score it per `assessment/scoring-guide.md`. Compare the resulting profile against `assessment/worked-example.md`'s original two-capability profile (Knowledge: 1, Intelligence: 1, Autonomy: 0, Control: 0, Operations: 1, Evolution: 0). Which domains improved, and does the improvement trace specifically to Lab 04's shared infrastructure investment rather than to the new capability itself? What does this suggest about the relationship between portfolio growth and maturity-model scores?

## Exercise 2 — The suggestion becomes an action

Design what would need to change — architecturally, not just as a UX toggle — if the organization later decided the workload assistant's suggestions were reliable enough (per accumulated `O-02` evaluation data) to warrant a "one-click execute" option. Walk through the `A-01` reclassification, the new Envelope tools required, and the `C-02` policy this would need, referencing Lab 03's existing ticket-agent enforcement as a potential integration point rather than a from-scratch build.

## Exercise 3 — A fourth capability, stress-testing the reuse claim

Sketch (briefly) a fourth hypothetical capability that would stress-test this lab's shared-infrastructure claims differently — e.g., one requiring a knowledge source with much stricter regulatory retention requirements than anything in Labs 01–04. Where would the existing shared infrastructure's assumptions (from `E-01`, `I-03`, or `K-02`) most likely need to be revisited rather than simply extended?

## Exercise 4 — Roadmap this portfolio forward

Using `assessment/roadmap-template.md`, produce the next roadmap for this three-capability portfolio based on Exercise 1's assessment results. Does the prioritization principle (Control before further Autonomy investment) still apply the same way it did in the original two-capability roadmap, or has the portfolio's maturity progressed enough that a different domain is now the most urgent priority?
